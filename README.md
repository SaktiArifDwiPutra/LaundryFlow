# LaundryFlow

LaundryFlow is a Flutter mobile application
for laundry operations powered by Odoo 20 Enterprise.

## Components

- Flutter mobile application
- Odoo custom addon
- Odoo Contacts and product catalog
- Odoo Invoicing / Accounting
- Infinys WhatsApp Gateway and WAPI

## Repository Structure

- `backend/`: Odoo custom addons
- `mobile/`: Flutter application
- `docs/`: API contracts and project documentation
